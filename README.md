

# Windows 12 网页桌面仿真

版本 **1.7**。使用原生 HTML、CSS 和 JavaScript 构建的交互式桌面，采用接近 Windows 11 的界面与 Fluent Glass 材质。

## 运行

下载项目或 Release 压缩包，解压后用现代浏览器打开 `index.html`。无需安装依赖或构建。桌面功能可离线使用；访问外部网站和搜索需要联网。

## 锁屏与登录

1. 打开页面后，先显示壁纸、时间和日期。
2. 按任意键或点击屏幕，进入密码界面；用于唤起的按键不会写入密码框。
3. 首次使用输入初始密码 **123456**；已更改密码时输入自定义密码。按 Enter 或点击箭头登录。
4. 密码页按 Esc 返回锁屏。锁定或重新开始也会回到壁纸时钟页。

密码属于当前浏览器内的网页桌面账户，与 Windows 系统账户相互独立。

## 功能

- 本地 SVG 蓝色折叠壁纸与亮／暗主题。
- 设置 → 账户 → 你的信息支持更改头像和用户名，登录页、开始菜单及设置同步显示。
- 设置 → 账户 → 登录选项支持更改登录密码、确认新密码及可选密码提示，刷新后继续使用。
- 浮动任务栏、开始菜单、搜索占位、通知中心、桌面右键菜单。
- 多窗口打开、拖拽、四边／四角拉伸、最小化、最大化／还原、关闭与层级切换。
- 桌面与文件资源管理器支持新建文本文档、快捷方式和文件夹，创建后立即显示图标。
- 文本文档可双击编辑、自动保存和下载；文件夹支持嵌套、新建、浏览与整理。
- 快捷方式可打开内置应用、指定文件／文件夹或 HTTP(S) 网址，文件改名后仍可定位。
- 支持重命名、剪切、复制、粘贴、删除与回收站还原，重名复制自动编号。
- 可以将桌面或资源管理器中的文件、文件夹、快捷方式拖到回收站图标或已打开的回收站窗口。
- 文件资源管理器、便笺、计算器、照片、设置、终端、日历、时钟、音乐等 12 个内置演示应用。
- 内置 Edge 风格浏览器支持外部 HTTP(S) 网址、关键词搜索、多标签页、前进／后退、刷新和主页；网址快捷方式可直接打开新标签页。
- 便笺自动保存到当前浏览器；音乐使用 Web Audio 本地生成。
- 适配窄屏、键盘焦点与减少动态效果偏好。

## 更改头像和用户名（v1.7）

1. 打开设置 → 账户 → 你的信息；也可点击开始菜单底部的账户头像直接进入。
2. 在“用户名”中输入 1 至 32 个字符，支持中文与表情，保存时去掉首尾空格。
3. 点击“浏览文件”选择 JPG、PNG 或 WebP 图片（最大 5 MB、4000 万像素以内），自动居中裁切并压缩为 256 × 256 头像。也可选择预设头像或恢复默认头像。
4. 预览确认后点击“保存”。登录界面、开始菜单、设置首页及登录选项同步显示，刷新或重新登录后继续保留。
5. 点击“取消”或返回“设置”放弃尚未保存的修改。选图失败或保存失败时，会显示提示并保留原资料。

资料仅保存在当前浏览器，不上传图片，也不更改 Windows 系统账户、登录密码或桌面文件。清除网站数据会重置这些资料。其他标签页修改资料后，当前编辑页会提醒重新打开，避免覆盖新资料。

## 批处理文件（v1.6）

1. 桌面空白处右键 → 新建 → Windows 批处理文件 (.bat)，或 Windows 命令脚本 (.cmd)。资源管理器的“新建”也提供这两种文件。
2. 右键文件 → 编辑，在记事本中修改，自动保存；点击“运行”或双击文件，在终端运行。新建文件自带欢迎示例。
3. 现有文本文档可用 F2 改成 `.bat`／`.cmd`，图标、类型和默认打开方式随之更新；后缀不区分大小写。改回 `.txt` 后双击编辑。
4. 支持 `@echo off/on`、`echo`、`echo.`、`rem`／`::` 注释、`cls`、`title`、`pause`、`set 名称=值`、`%名称%`、`%~nx0`、`%ERRORLEVEL%`、`dir`／`dir /b`、`date`、`time`、`whoami`、`start`／`open` 内置应用、`theme`、`exit /b [代码]`。
5. `pause` 后在终端输入框按任意键或点击“继续运行”；Ctrl+C 或“停止”可中止。再次打开脚本会停止上一次运行，关闭终端也会停止。
6. 文件可复制、移动、下载、删除和还原，刷新后保留。下载保留原后缀和 UTF-8 文本。

示例：

```bat
@echo off
title Windows 12
set name=Windows 12
echo 欢迎使用 %name%！
echo 当前脚本：%~nx0
start calc
pause
exit /b 0
```

这些脚本在网页仿真终端内执行常用命令，`dir` 显示脚本所在的虚拟文件夹；`start calc`、`start notepad`、`start explorer` 对应内置计算器、便笺和资源管理器。不会调用电脑的 CMD 或运行系统程序。不支持管道、重定向、循环、条件跳转和完整 Windows 批处理语法，未支持命令会显示行号提示。单份脚本最多 1000 行、100000 字符。

## 更改登录密码（v1.5）

1. 打开设置，点击账户一栏的“登录选项”。
2. 在“密码”卡片中点击“更改”。
3. 输入当前密码、新密码与确认密码，可填写密码提示。
4. 点击“更改密码”，看到“密码已更改”后，下次锁定或重新登录时使用新密码。

新密码为 6 至 128 个字符，区分大小写，两次输入需一致，且不能与当前密码相同。可用“显示密码”核对输入，取消不会修改密码。初始密码为 `123456`。

密码设置保存于当前浏览器；改成自定义密码后，登录页不再显示初始密码，展开“登录选项”可查看自己填写的提示。网页仅保存带随机盐的 PBKDF2 派生值，不保存新密码原文。清除网站数据会重置密码，也会清除本地桌面文件；不同浏览器或网址的账户数据相互独立。

## 外部网址浏览（v1.4）

1. 点击任务栏或开始菜单中的 Microsoft Edge。
2. 在地址栏输入完整的 HTTP(S) 网址，或输入域名（自动补全 `https://`），按 Enter／点击箭头访问。也可输入关键词，使用必应搜索。
3. “＋”新建标签页；点击标签切换，点击标签上的“×”关闭。各标签页保留独立导航记录。
4. 工具栏提供后退、前进、刷新和主页。前进／后退记录从地址栏、主页入口打开的页面；跨域网页内部的跳转不能同步到仿真地址栏和导航记录。
5. 支持嵌入的网站会在窗口内显示。若网站空白、拒绝连接或跳转异常，点击提示栏“在新标签页打开”或地址栏旁的“↗”，在宿主浏览器标签页中访问。
6. 桌面右键新建“网址”快捷方式后，双击会恢复内置浏览器并打开独立标签页。

网站可通过自身的嵌入策略拒绝显示在网页窗口中，无法保证所有站点在窗口内显示；项目提供直接外部打开入口。iframe 的跨域加载事件也不能可靠证明页面显示成功，界面不会把请求结束误报为成功加载。参见 [MDN iframe 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)。

标签页和导航记录仅保留在当前打开的浏览器应用中；关闭应用或刷新桌面后回到新标签页。原有桌面文件和快捷方式仍按浏览器本地存储保留。浏览器工具栏获得焦点时，可使用 Ctrl+L 聚焦地址栏、Alt+方向键前进／后退、F5 刷新当前页；网页内的快捷键由宿主浏览器及站点处理。

## 拖入回收站（v1.3）

- 按住桌面项目或资源管理器中的文件行，拖到桌面回收站图标后松开，即可移到回收站；也可以拖到已打开的回收站窗口内容区域。
- 拖动中显示项目预览；进入回收站区域时高亮目标，并显示“移到 回收站”。
- 拖到其他位置松开会取消，项目保留在原位置。拖动中按 Esc 也可以取消。
- 文件夹中的内容会一起进入回收站；点击“还原”后恢复原位置和内容，快捷方式的目标不变。
- 删除和还原会保存在当前浏览器，刷新后仍然保留。

## 桌面文件（v1.2）

1. 右键桌面空白处 → 新建 → 选择“文件夹”“快捷方式”或“文本文档”。
2. 新建文件夹／文本后直接输入名称，Enter 确认；双击图标打开。
3. 文本逐份独立保存；编辑器会自动保存，也可使用“保存”或 Ctrl+S。“下载文本”可导出真实 UTF-8 文本文件。
4. 文件夹内右键空白处或点击工具栏“新建”可继续创建。使用剪切／复制／粘贴在桌面和文件夹之间整理项目。
5. 快捷方式创建向导支持选择内置应用、已有文件／文件夹，以及网站地址。
6. 删除的项目进入回收站，打开回收站后点击“还原”即可恢复。

文件和文件夹存放在当前浏览器的 localStorage 中，刷新后保留；它们属于网页桌面，不会直接写入 Windows 桌面或磁盘目录。清除网站数据会清除这些项目；更换浏览器、网址／端口或使用无痕窗口时，存储相互独立。重要文本可先下载备份。

| 文件操作 | 方式 |
| --- | --- |
| 打开文件／文件夹 | 双击图标，或选中后按 Enter |
| 新建文件夹 | Ctrl + Shift + N |
| 重命名 | 选中后 F2 |
| 剪切／复制／粘贴 | Ctrl + X／C／V，或右键菜单／工具栏 |
| 删除到回收站 | 拖到回收站，或选中后 Delete |
| 取消文件拖动 | Esc，或在回收站以外松开 |
| 保存当前文本 | Ctrl + S |

## 窗口拉伸（v1.1）

- 四边和四角共 8 个方向可拖动调整尺寸，鼠标指针会显示相应缩放方向。
- 各应用具有最小尺寸；窄屏下会按可用空间调整，拉伸不会盖住任务栏。
- 最大化时隐藏拉伸手柄；还原或最小化后重新打开，保留自定义位置和尺寸。
- 浏览器窗口变小时自动收拢桌面窗口，支持窄屏中的横向和纵向调整。
- 通过 Tab 聚焦拉伸边缘，方向键每次调整 10px；按住 Shift 每次调整 1px。

## 项目文件

- `index.html`：页面结构、SVG 图标与壁纸。
- `styles.css`：设计 tokens、主题、动效与响应式布局。
- `app.js`：锁屏、登录、窗口管理及应用交互。
- `account.js`：本地密码保存、登录校验及账户登录选项。
- `profile.js`：个人资料保存、图片头像处理与账户信息界面。
- `batch.js`：批处理后缀关联、命令解释与仿真终端。
- `browser.js`：网址解析、搜索、标签页、导航记录和嵌入页面。
- `tests/browser.test.cjs`：网址与导航行为测试，运行 `node tests/browser.test.cjs`。
- `filesystem.js`：可持久化的文件树、文本、快捷方式与回收站。
- `workspace-ui.js`：桌面文件、资源管理器、记事本与新建向导。
- `tests/filesystem.test.cjs`：文件系统行为测试，运行 `node tests/filesystem.test.cjs`。
- `VERSION`：当前版本号。
- `CHANGELOG.md`：版本记录。
- `使用与验证.txt`：详细操作与验证记录。

所有图标与壁纸均由内联 SVG 或 CSS 绘制，无外部 UI 框架、图标库和图片依赖。
