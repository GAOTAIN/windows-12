# Windows 12 网页桌面仿真

版本 **1.0**。使用原生 HTML、CSS 和 JavaScript 构建的交互式桌面，采用接近 Windows 11 的界面与 Fluent Glass 材质。

## 运行

下载项目或 Release 压缩包，解压后用现代浏览器打开 `index.html`。无需安装依赖、构建或联网。

## 锁屏与登录

1. 打开页面后，先显示壁纸、时间和日期。
2. 按任意键或点击屏幕，进入密码界面；用于唤起的按键不会写入密码框。
3. 输入演示密码 **123456**，按 Enter 或点击箭头登录。
4. 密码页按 Esc 返回锁屏。锁定或重新开始也会回到壁纸时钟页。

密码校验属于浏览器内的界面演示。

## 功能

- 本地 SVG 蓝色折叠壁纸与亮／暗主题。
- 浮动任务栏、开始菜单、搜索占位、通知中心、桌面右键菜单。
- 多窗口打开、拖拽、最小化、最大化／还原、关闭与层级切换。
- 文件资源管理器、便笺、计算器、照片、设置、终端、日历、时钟、音乐等 12 个内置演示应用。
- 便笺自动保存到当前浏览器；音乐使用 Web Audio 本地生成。
- 适配窄屏、键盘焦点与减少动态效果偏好。

## 常用操作

| 操作 | 方式 |
| --- | --- |
| 打开开始菜单搜索 | Ctrl + K |
| 关闭浮层／从密码页返回锁屏 | Esc |
| 最大化／还原窗口 | 双击标题栏 |
| 恢复最小化窗口 | 点击任务栏对应图标 |
| 切换主题 | 点击任务栏太阳／月亮按钮 |
| 锁定桌面 | 开始菜单 → 电源 → 锁定桌面 |

## 项目文件

- `index.html`：页面结构、SVG 图标与壁纸。
- `styles.css`：设计 tokens、主题、动效与响应式布局。
- `app.js`：锁屏、登录、窗口管理及应用交互。
- `VERSION`：当前版本号。
- `CHANGELOG.md`：版本记录。
- `使用与验证.txt`：详细操作与验证记录。

所有图标与壁纸均由内联 SVG 或 CSS 绘制，无外部 UI 框架、图标库和图片依赖。
